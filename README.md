# MSc AI & ML Case Studies – Sainadh Bahadursha

I am **Sainadh Bahadursha**, and I have completed my **Master of Science in Artificial Intelligence and Machine Learning** from **Scaler Neovarsity** affiliated under **Woolf University**. This repository presents a comprehensive collection of case studies completed as part of my coursework. These case studies span various domains of Data Science, Machine Learning and Deep Learning showcasing the breadth and depth of my hands-on experience.

## Case Study List

Below is the list of case studies included in this repository:

1. **Target Brazil SQL Data Analysis Case Study**  
   → Business insights using SQL queries and Excel graphs.

2. **Netflix Data Exploration and Visualization Case Study**
   → EDA with visual storytelling using matplotlib and seaborn.

3. **Aerofit Descriptive Stats and Probability Case Study**  
   → Applied statistics for customer segmentation and business understanding.

4. **Walmart Confidence Intervals and CLT Case Study**  
   → Statistical inference using confidence intervals and Central Limit Theorem.

5. **Yulu Hypothesis Testing Case Study**  
   → Hypothesis testing for product and user engagement validation.

6. **Delhivery Feature Engineering Case Study**  
   → Feature transformation and encoding for logistics business analysis.

7. **Jamboree Linear Regression Case Study**  
   → Predictive modeling using simple linear regression and assumptions verification.

8. **Loan Tap Logistic Regression Case Study**  
   → Binary classification and credit risk modeling using logistic regression.

9. **Ola Ensemble Learning Case Study**  
   → Tree ML models along with Boosting, bagging, and stacking techniques for churn prediction.

10. **Scaler Clustering Case Study**  
   → Unsupervised learning using KMeans, GMM, DBSCAN, and Hierarchical Clustering.

11. **Adease Time Series Forecasting Case Study**  
   → Forecasting sales using Exponential Smoothing, ARIMA, SARIMAX, and Prophet models.

12. **Zee Recommendation System Case Study**  
   → Collaborative filtering, Matrix decomposition and Similarity Based recommendation algorithms.

13. **Porter Neural Network Regression Case Study**  
   → ANN-based regression model built using TensorFlow/Keras.

14. **NinjaCart Image Classification CV Case Study**  
   → CNN-based vegetable classification using transfer learning.

15. **Flipit News Classification NLP Case Study**  
   → Text classification using NLP pipeline and ML models.

16. **Twitter Named Entity Recognition NLP Case Study**  
   → Sequence tagging using BiLSTM and CRF for named entity recognition.
